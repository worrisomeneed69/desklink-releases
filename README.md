# DeskLink — binarki

Repozytorium tylko do wydawania plików binarnych DeskLink (klon pulpitu zdalnego,
Windows 11 / Linux / Wine). Zrzuty obrazów i kody źródłowe są osobno — tutaj leżą
wyłącznie zasoby release, żeby link do pobrania był stały i bez limitu czasu.

| Plik | Co to jest |
|---|---|
| `DeskLink.exe` (gui) | aplikacja okienkowa: host i kontroler w jednym |
| `DeskLink-cli.exe` | to samo w wersji terminalowej (`--relay`, `connect`, `relay`) |
